# Пауза выполнения и запрос данных у пользователя

## Проблема

В медицинских алгоритмах часто требуется ввод данных во время выполнения:
- **Измерение показателей** (давление, температура) после действий
- **Ожидание эффекта** препарата или процедуры
- **Динамический мониторинг** состояния пациента

Без механизма паузы алгоритм не может корректно работать с такими сценариями.

## Решение

Движок поддерживает паузу выполнения и запрос данных у пользователя через атрибуты узлов.

## Использование в узлах

### В Action узле

Добавьте атрибут с префиксом `require:` или `требуется:` для указания полей, которые нужно ввести:

**Пример:**
```
Атрибут 1:
  name: "require:bloodPressure.systolic"
  value: "Введите систолическое давление"

Атрибут 2:
  name: "require:bloodPressure.diastolic"
  value: "Введите диастолическое давление"
```

**Поддерживаемые форматы:**
- Простые поля: `require:temperature`
- Вложенные поля: `require:bloodPressure.systolic`
- Сообщение для пользователя: значение атрибута используется как сообщение

### Как это работает

1. **Узел выполняется** → проверяет наличие требуемых полей
2. **Если поля отсутствуют** → выполнение приостанавливается
3. **Пользователю показывается форма** для ввода данных
4. **После ввода** → выполнение продолжается с обновлёнными данными

## Пример: Циклический мониторинг

### Схема алгоритма:

1. **Start** → **Action: "Измерить давление"**
   - Атрибут: `require:bloodPressure.systolic` = "Введите систолическое давление"
   - Атрибут: `require:bloodPressure.diastolic` = "Введите диастолическое давление"
   
2. **Action** → **Condition: "Давление < 140/90?"**
   - Если ДА → **Finish**
   - Если НЕТ → **Action: "Принять препарат"** → возврат к шагу 1

### Поведение:

- При первом выполнении узла "Измерить давление" выполнение остановится
- Пользователь введёт данные давления
- Алгоритм продолжит выполнение
- В цикле при следующем измерении снова запросит данные

## Использование в коде

### Базовое использование (с UI)

UI автоматически обрабатывает паузу и показывает форму для ввода данных:

```typescript
const engine = new ExecutionEngine({
  onDataRequired: async (requiredFields, currentData, message) => {
    // UI автоматически покажет форму для ввода
    // Promise будет разрешён после ввода данных пользователем
    return new Promise((resolve) => {
      // Разрешается в UI после нажатия "Продолжить"
    });
  }
});
```

### Программное использование

Если нужно обработать паузу программно:

```typescript
const engine = new ExecutionEngine({
  onDataRequired: async (requiredFields, currentData, message) => {
    console.log('Требуются данные:', requiredFields);
    console.log('Сообщение:', message);
    
    // Запрашиваем данные у пользователя (например, через модальное окно)
    const newData = await promptForData(requiredFields, message);
    
    return newData;
  }
});

const result = await engine.execute('main', patientData);

if (result.paused) {
  console.log('Выполнение приостановлено');
  console.log('Требуемые поля:', result.requiredData);
  console.log('Сообщение:', result.message);
}
```

## Структура результата при паузе

```typescript
{
  success: false,
  paused: true,
  requiredData: ['bloodPressure.systolic', 'bloodPressure.diastolic'],
  message: 'Введите данные давления',
  steps: [...], // История выполнения до паузы
  finalVariables: {...}, // Переменные на момент паузы
  executionTime: 1234
}
```

## Продолжение выполнения

После получения данных можно продолжить выполнение:

```typescript
// Получаем данные от пользователя
const additionalData = {
  bloodPressure: {
    systolic: 130,
    diastolic: 85
  }
};

// Объединяем с текущими данными
const updatedData = { ...result.patientData, ...additionalData };

// Продолжаем выполнение
const continuedResult = await engine.execute('main', updatedData);
```

## Важные моменты

1. **Данные сохраняются** - все данные пациента сохраняются на момент паузы
2. **Можно вводить частичные данные** - не обязательно вводить все поля сразу
3. **Выполнение продолжается с того же места** - следующий узел выполнится после ввода данных
4. **Можно отменить** - пользователь может отменить выполнение

## Отладка

Чтобы увидеть, когда происходит пауза, можно использовать callback `onStep`:

```typescript
const engine = new ExecutionEngine({
  onStep: (step) => {
    if (step.result?.requiresData) {
      console.log('Требуются данные:', step.result.requiredFields);
      console.log('Сообщение:', step.result.pauseMessage);
    }
  }
});
```
