# Отладка бесконечных циклов

## Проблема: "Возможен бесконечный цикл"

Если вы видите ошибку "Возможен бесконечный цикл: узел ... посещён 51 раз", это означает, что условие выхода из цикла никогда не выполняется.

## Причины

### 1. Данные не обновляются в цикле

**Проблема:** Начальные данные пациента не меняются, поэтому условие выхода всегда false.

**Пример:**
- Начальные данные: `{"bloodPressure": {"systolic": 160, "diastolic": 95}}`
- Условие выхода: `"АД стабилизировалось < 140/90?"`
- Результат: `160 < 140` = false, `95 < 90` = false → цикл бесконечный

**Решение:**
- Добавьте в цикл узлы, которые запрашивают обновлённые данные через `require:`
- Или используйте callback `onPatientDataUpdate` для симуляции изменений

### 2. Условие выхода задано неправильно

**Проблема:** Условие не соответствует логике алгоритма.

**Пример:**
- Условие: `"temperature > 100"` (невозможно для человека)
- Результат: условие никогда не выполнится

**Решение:**
- Проверьте условие выхода в узле цикла
- Убедитесь, что условие может стать true при обновлении данных

### 3. Условие выхода отсутствует

**Проблема:** В цикле нет условия выхода, только максимальное количество итераций.

**Решение:**
- Добавьте условие выхода в настройках цикла
- Или увеличьте максимальное количество итераций

## Как исправить

### Вариант 1: Запрос данных в цикле

Добавьте в подпроцесс цикла узел Action с атрибутами:
```
name: "require:bloodPressure.systolic"
value: "Введите систолическое давление"

name: "require:bloodPressure.diastolic"  
value: "Введите диастолическое давление"
```

Тогда на каждой итерации алгоритм будет запрашивать новые данные.

### Вариант 2: Начать с правильных данных

Если алгоритм не запрашивает данные, начните с данных, которые уже удовлетворяют условию:

```json
{
  "age": 60,
  "bloodPressure": {
    "systolic": 130,
    "diastolic": 85
  }
}
```

### Вариант 3: Использовать callback для обновления

```typescript
const engine = new ExecutionEngine({
  onPatientDataUpdate: async (updates, currentData) => {
    // Симулируем снижение давления на каждой итерации
    if (currentData.bloodPressure) {
      return {
        ...currentData,
        bloodPressure: {
          systolic: Math.max(120, currentData.bloodPressure.systolic - 5),
          diastolic: Math.max(80, currentData.bloodPressure.diastolic - 3)
        }
      };
    }
    return currentData;
  }
});
```

## Отладка

Откройте консоль браузера (F12) и посмотрите логи:
- `[Loop]` - информация о цикле
- `[Condition]` - информация об оценке условий

Логи покажут:
- Какое условие проверяется
- Какие данные используются
- Почему условие не выполняется

## Пример правильного цикла

1. **Start** → **Action: "Начать мониторинг"**
2. **Action** → **Loop: "Проверка давления"**
   - Условие выхода: `bloodPressure.systolic < 140 && bloodPressure.diastolic < 90`
   - Подпроцесс: "Измерение и обработка"
3. **Подпроцесс "Измерение и обработка":**
   - **Action: "Измерить давление"**
     - `require:bloodPressure.systolic` = "Введите систолическое давление"
     - `require:bloodPressure.diastolic` = "Введите диастолическое давление"
   - **Action: "Принять препарат"** (если нужно)
4. **Loop** → **Condition: "Давление < 140/90?"**
   - Если ДА → **Finish**
   - Если НЕТ → возврат в цикл
