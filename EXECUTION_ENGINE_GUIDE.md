# Руководство по использованию движка исполнения

## Как открыть страницу выполнения

1. **Запустите проект** (если еще не запущен):
   ```bash
   npm run dev
   ```

2. **Откройте браузер** и перейдите на главную страницу (обычно `http://localhost:5173`)

3. **На главной странице** вы увидите список рекомендаций (алгоритмов)

4. **Нажмите кнопку "🚀 Выполнить"** на любой карточке рекомендации

   Или перейдите напрямую по адресу:
   ```
   http://localhost:5173/execution/[ID_РЕКОМЕНДАЦИИ]
   ```

## Использование интерфейса

### 1. Ввод данных пациента

В текстовом поле введите данные пациента в формате JSON. Пример:

```json
{
  "age": 45,
  "temperature": 38.5,
  "cough": true,
  "bloodPressure": {
    "systolic": 150,
    "diastolic": 90
  }
}
```

### 2. Запуск выполнения

Нажмите кнопку **"Выполнить алгоритм"**. Движок:
- Загрузит схему процесса
- Пройдёт по всем узлам
- Примет решения на основе данных пациента
- Вернёт результат выполнения

### 3. Просмотр результатов

После выполнения вы увидите:

- **Статус выполнения** (✅ Успешно или ❌ Ошибка)
- **Количество шагов** - сколько узлов было выполнено
- **Время выполнения** - сколько миллисекунд заняло выполнение
- **История выполнения** - детальная информация о каждом шаге:
  - Название узла и его тип
  - Результат условия (для condition узлов)
  - Детали выполнения
  - Ошибки (если были)
- **Финальные переменные** - все переменные, созданные во время выполнения

## Примеры данных пациента

### Простой пример
```json
{
  "age": 30,
  "temperature": 36.6
}
```

### Пример с условиями

## Навигация

- **"Редактор схемы"** - открывает Flow Editor для редактирования схемы
- **"К списку"** - возвращает на главную страницу со списком рекомендаций

## Что происходит под капотом

1. Движок загружает схему процесса из `BpmnStore`
2. Находит начальный узел (по label "Начало" или узел без входящих рёбер)
3. Последовательно выполняет узлы:
   - **Action** - выполняет действие, создаёт переменные
   - **Condition** - оценивает условие, выбирает путь (ДА/НЕТ)
   - **Subprocess** - выполняет подпроцесс рекурсивно
   - **Loop** - выполняет цикл до условия выхода
4. Завершается на finish-узле или когда нет следующего узла
5. Возвращает полную историю выполнения и финальные переменные

## Отладка

Если что-то не работает:

1. **Проверьте формат JSON** - данные должны быть валидным JSON
2. **Проверьте схему** - убедитесь, что схема загружена и имеет начальный узел
3. **Посмотрите в консоль браузера** - там могут быть дополнительные ошибки
4. **Проверьте историю выполнения** - она покажет, на каком шаге произошла ошибка

## Примеры условий

В condition узлах можно использовать следующие условия:

- `age > 18` - числовые сравнения
- `temperature >= 37.5` - сравнения с плавающей точкой
- `has('cough')` - проверка наличия ключа
- `temperature > 37.5 && has('cough')` - составные условия
- `bloodPressure.systolic > 140` - доступ к вложенным свойствам
